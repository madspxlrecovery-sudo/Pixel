# Pixel Dungeons-Compatible Design System

This is an original Pixel implementation constrained by official Minecraft/Dungeons evidence.

## Foundation files
- `assets/css/foundation/typography.css`
- `assets/css/foundation/tokens.css`
- `assets/css/foundation/dungeons-core.css`

## Component philosophy
Components should be boringly consistent. Once a frame, button, title plaque, state treatment or control hint is validated against a Dungeons reference, reuse it instead of redesigning it per screen.

## Planned component set
- Screen scene layer
- Dim/contrast overlay
- Dungeons-style frame
- Dark translucent panel
- White title plaque
- Primary action button
- Locked panel state
- Selected panel state
- Currency HUD
- Controller/keyboard prompt row
- Banner selector
- Reward reveal shell

See `COMPONENTS.md` for component contracts.
