# Visual Reference Policy

Do not copy official Minecraft / Minecraft Dungeons marketing art, game textures or Mojang web-theme image assets into this folder.

This folder stores only:
- source notes
- links
- Pixel-created reference diagrams
- user-owned screenshots when appropriate

Official visual source links are tracked in `docs/research/OFFICIAL_SOURCES.md` and `docs/research/source-manifest.json`.

For production backgrounds, create original Pixel art/screenshots from the user’s own server/content rather than republishing Mojang marketing imagery.
